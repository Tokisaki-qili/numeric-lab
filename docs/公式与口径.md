# 公式与口径

> 这里定义"数字怎么算"。**代码必须按这里算**，报告里的每个数字都要能指回本文某一行。
> 先自己手算一遍（N0-0），再实现；实现完用这里的参考值对账。

## 1. 抽卡

参数（见 `config/gacha.yaml`）：

| 符号 | 含义 | 示例值 |
|---|---|---|
| `p0` | 单抽基础概率 | 0.006 |
| `S` | 软保底起点（第几抽开始加概率） | 74 |
| `step` | 软保底每抽递增 | 0.06 |
| `H` | 硬保底（第几抽必出） | 90 |

第 i 抽（i 从 1 开始）出五星的概率：

```
p_i = p0                          , i <  S
      p0 + step * (i - S + 1)     , S <= i < H
      1                           , i >= H
```

第 i 抽**恰好**出五星的概率（之前都没出）：

```
P_i = p_i * Π_{j<i} (1 - p_j)
```

- 期望抽数 `E = Σ i * P_i`
- 中位数 P50：累计概率首次 ≥ 0.5 的抽数
- P90：累计概率首次 ≥ 0.9 的抽数

**参考值**（本仓库参数下，先自己手算再核对）：`E ≈ 62.3 抽`，`P50 = 76 抽`，`P90 = 80 抽`。
（另：不加保底时，90 抽全空的概率 `(1-p0)^90 ≈ 58.2%`。）

## 2. 掉落

权重表：`weight_i / Σweight` 即该物品概率。支持"每 10 次必出稀有"这类保底时，写法与抽卡相同。

验收口径：10 万次模拟中各物品占比与理论概率相差 < 2%（绝对差 < 0.5 个百分点）。

## 3. 成长曲线

`exp(L)` = 从 L 级升到 L+1 级所需经验，公式：

```
exp(L) = round(50 * L ^ 1.6)
```

到 L 级的累计经验 = `Σ_{k=1}^{L-1} exp(k)`（即从 1 级升到 L 级要花的总经验）。

**参考值**（对账用）：

| 等级 L | 本级经验 exp(L) | 升到 L 级累计 |
|---|---|---|
| 1 | 50 | 0 |
| 10 | 1,991 | 6,687 |
| 20 | 6,034 | 43,440 |
| 30 | 11,544 | 127,481 |
| 40 | 18,292 | 272,332 |
| 50 | 26,141 | 489,709 |
| 60 | 34,995 | 790,167 |
| 70 | 44,784 | 1,183,425 |
| 80 | 55,452 | 1,678,566 |
| 90 | 66,951 | 2,284,161 |

战力 = `Σ (属性 × 权重)`，权重写在 `growth.yaml`。

## 4. 经济循环

- 日净产出 = 日产出合计 − 日消耗合计
- 30 天累计净值 = 逐日累加日净产出
- **缺口日** = 累计净值首次 < 0 的那一天
- 30 天缺口 = Σ 30 天消耗 − Σ 30 天产出（正数表示资源不够）

验收口径：缺口的出现必须能指到具体某一天、某一项资源。
